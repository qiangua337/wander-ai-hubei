# Wander AI · 寻游湖北

[公开网站](https://wander-ai-hubei.pages.dev/) · React + TypeScript + Tailwind CSS 的湖北旅行网站。

首页提供 6 个热门推荐，再按全省 17 个市州、直管市和林区浏览 70 个精选去处。每个去处都有看点解读、建议停留时长与实用提示；17 份城市攻略按上午、下午、晚上组织路线，包含交通、住宿片区、地方餐食和官方资料链接。

## 主要功能

- 热门推荐、按城市浏览、自然 / 人文 / 收藏筛选与关键词搜索
- 目的地攻略与 2–4 天城市主线，县域支线按地理位置说明替换
- 按城市、天数、出发日期与节奏整理路线，复制或下载完整文本清单
- 浏览器本地收藏；响应式导航与手机长攻略阅读
- 本地景点实拍与文物照片，网页和 SOURCES.md 提供署名与许可

## 本地运行

需要 Node.js 24.21.0（见 `.node-version`），锁文件固定依赖版本。

```bash
npm ci
npm run dev
npm run check
npm run build
npm run preview
```

开发地址为 `http://127.0.0.1:5173/`；生产构建输出 `dist/`。字体使用本地打包的 Manrope 与 Noto Sans SC。

## 文件结构

- `src/App.tsx`：页面、筛选、收藏与弹窗状态
- `src/data/cities.ts`：17 份城市攻略与官方资料
- `src/data/destinations.ts`：70 个精选去处及看点
- `src/data/photos.ts`、`extraPhotos.ts`：图片署名和场景映射
- `src/travel.ts`：组合筛选、路线整理与文本导出
- `src/components/TravelGuide.tsx`、`Planner.tsx`：完整攻略与规划界面
- `src/components/DestinationCard.tsx`：热门图卡与城市条目
- `SOURCES.md`：图片许可与旅行资料

## 内容与验证

覆盖的是精选旅行去处，不宣称收录全部景区。路线与时段为编辑建议；未接入真实账号、库存、订单、支付与 AI 服务。示例评价均已标识。

内容完整性、城市对应关系、关键词与收藏筛选、路线边界、原始数据不被规划修改、跨月日期和图片文件已检查。浏览器验证了城市搜索、70 条分页、收藏刷新保留、无结果提示、行程复制与下载、Escape 关闭和焦点循环；390px 手机与 768px 平板无横向溢出。

原始页面框架来自用户 [Figma 线框图](https://www.figma.com/design/YDADbdkQCoLAyzgBFPrYG8?node-id=4-31)，保持 Wander AI 品牌与山水视觉。
