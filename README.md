# Wander AI · 寻游湖北

[公开网站](https://wander-ai-hubei.pages.dev/) · React + TypeScript + Tailwind CSS 的湖北旅行网站。

首页以红色主题搭配荆楚山河实景展开，提供 6 个热门推荐、2/5/7 天经典路线，再按全省 17 个市州、直管市和林区浏览 70 个精选去处。每个去处都有看点解读、建议停留时长与实用提示；17 份城市攻略按上午、下午、晚上组织路线，包含交通、住宿片区、地方餐食和官方资料链接。

## 主要功能

- 山河实景首屏、紧凑六地推荐、中文章节、深红路线目录与城市索引
- 礼乐、江流、城郭三组文化导览，含器物/地理/城市背景、看点、景点入口与资料来源
- 山水、人文、亲子研学、收藏及半日/深度游筛选；风味关键词搜索
- 单城逐日自选与 2/5/7 天路线；按同行人群、交通、预算、兴趣和节奏组合
- 每日时段、交通衔接、餐食与逐晚住宿，跨城上午保留为转场
- 17 个市州各两组住宿片区和两组用餐建议，含适合人群、订前检查及地图查询
- 按人数、房间、晚数计算预算额度；非实时报价，并列明排除项
- 浏览器保存最多 5 份行程、草稿恢复、文本下载、复制及分享设置链接
- 同城继续探索、FAQ、浏览筛选与刷新位置记忆、浮动选城市/回顶部
- 图片许可、官方资料、SEO 元信息、robots/sitemap 与静态资产缓存

## 本地运行

需要 Node.js 24.21.0（见 `.node-version`），锁文件固定依赖版本。

```bash
npm ci
npm run dev
npm run check
npm test
npm run build
npm run preview
```

开发地址为 `http://127.0.0.1:5173/`；生产构建输出 `dist/`。字体使用本地打包的 Manrope、Noto Sans SC 与 Noto Serif SC，无需访问外部字体 CDN。Noto Serif SC 的 OFL 授权位于 public/fonts/OFL-NotoSerifSC.txt。

## 文件结构

- `src/App.tsx`：页面、筛选、收藏与弹窗状态
- `src/data/cities.ts`：17 份城市攻略与官方资料
- `src/data/destinations.ts`：70 个精选去处及看点
- `src/data/photos.ts`、`extraPhotos.ts`：图片署名和场景映射
- `src/travel.ts`：组合筛选、日期、城市攻略导出
- `src/planning.ts`：规划设置校验、跨城转场、预算、分享与完整行程导出
- `src/data/practical.ts`：17 市州住宿片区、餐食落点与逐晚安排
- `src/components/TravelGuide.tsx`、`Planner.tsx`、`PlannedTrip.tsx`：攻略与旅行规划室
- `DESIGN-NOTES.md`：GitHub 灵感、实现范围与预算/数据边界
- `src/components/DestinationCard.tsx`：热门图卡与城市条目
- `SOURCES.md`：图片许可与旅行资料

## 内容与验证

覆盖的是精选旅行去处，不宣称收录全部景区。路线与时段为编辑建议；未接入真实账号、库存、订单、支付与实时 AI 服务；规划依照编辑路线和所选条件组合。住宿片区为编辑建议，预算是预留额度，不承诺实际房价、班次或门票价格。示例评价均已标识。

内容完整性、城市对应关系、关键词与收藏筛选、路线边界、自选章节的去重排序与边界、原始数据不被规划修改、风味搜索、跨月日期和图片文件已检查，可用 `npm test` 复现。浏览器验证了七天亲子自驾方案、六晚住宿、按人数计算预算、保存反馈、复制清单、分享链接恢复、跨城日跳转和键盘页签。城市与时长筛选刷新后保留；320px/390px 手机及 768px 平板无横向溢出。文本导出内容已核对；内置浏览器下载未向工具暴露本地文件路径。

原始页面框架来自用户 [Figma 线框图](https://www.figma.com/design/YDADbdkQCoLAyzgBFPrYG8?node-id=4-31)，保持 Wander AI 品牌与山水视觉。

使用蓝灰、墨色和少量楚红，保留 Wander AI 品牌，去掉装饰性英文。整幅恩施峡谷实景承担封面，搭配编钟与古城的小幅入口；缩短首屏、章节间距和景点标题到图片的距离，六地卡片采用整齐紧凑的图文网格。
